Ona Nails — citas y administración

Ona Nails es un negocio de uñas. La web tiene como objetivo principal mostrar la información del negocio y permitir a las clientas agendar citas. Incluye un módulo de administración para gestionar citas, servicios y el día a día del negocio. Cliente desarrollado con React; API y lógica de negocio con Python (FastAPI). Es el proyecto con mayor probabilidad de pasar a producción para el uso real del establecimiento.

  • Landing e información del negocio y servicios.
  • Flujo de citas orientado a la experiencia de la clienta.
  • Administración: citas, servicios y operación interna.
